# ARCHIVE

Clothing marketplace interface hosted at https://xxtrarage.github.io/archive/.

This folder contains the complete static site: HTML, CSS, JavaScript, listing images, fonts, and font licenses. No build step is required.

## Local preview

From the repository root run `python3 -m http.server 8000`, then open http://localhost:8000/archive/.

## Hosting and updates

GitHub Pages serves the main branch. Changes committed to this folder publish to /archive/. Other sites in this repository are independent.

## Current behavior

This is a frontend demo. Profile settings, own listings, favorites and offers are saved in the current browser's localStorage. Accounts, payments and server-side storage are not connected. Existing data on a different domain does not transfer automatically.

Font licenses are included under assets/fonts/. Image and typography source records are under docs/.
